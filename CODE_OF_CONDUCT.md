# Code of Conduct

This project uses a direct, evidence-first collaboration standard.

## Expected Behavior

- Be specific and source-grounded.
- Challenge claims with evidence.
- Preserve public/private boundaries.
- Keep disagreement focused on the artifact.
- Avoid harassment, personal attacks, and disclosure of private information.

## Enforcement

Maintainers may reject or remove contributions that introduce unsafe claims, private information, hostile behavior, or protocol dilution.
