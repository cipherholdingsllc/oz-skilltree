# Security

This repository is a protocol and documentation package. It does not run a service, collect telemetry, or execute agent actions.

## Reporting

If you find a security issue in repo content or scripts, open a private report through the repository's security advisory flow when available. If that is unavailable, open a minimal issue that does not disclose exploit details.

## Sensitive Data Policy

Do not contribute:

- secrets or credentials
- private keys or tokens
- PHI or private patient data
- private customer/client data
- private implementation details
- collaborator names or personal data
- unsupported medical, legal, financial, or compliance claims

## Protocol Safety

High-risk work must use `failure-radar-max` and the approval ladder. The protocol must not be represented as a guarantee of correctness, security, compliance, or zero bugs.
