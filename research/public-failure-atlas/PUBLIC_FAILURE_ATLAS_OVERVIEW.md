# Public Failure Atlas Overview

`oz-skilltree` is informed by a private, source-locked Failure Atlas maintained outside this public-safe branch.

This public branch does not include raw/internal taxonomy artifacts. It includes public-safe protocol surfaces, schemas, examples, and boundary notes derived from that research discipline.

## Public Scope

The public Failure Atlas materials are intentionally scoped:

- no raw internal taxonomy
- no private provenance paths
- no PHI, secrets, or private implementation details
- no benchmark result claims
- no claim that the taxonomy is exhaustive
- no claim that `oz-skilltree` guarantees zero bugs
- no downgrade of private/internal classifications

## What Is Public Here

Public materials in this branch describe the operating surface:

- Failure Radar modes
- Countermap-50 shape
- YBR route selection
- OzReceipt memory
- `/oz-result` closeout
- Bug-Cognizant future-build prediction
- validation scripts and example fixtures

## What Is Excluded

The private source taxonomy, private source-lock artifact, raw research outputs, and private provenance paths are intentionally excluded from this branch and from this branch's history.

Future public summaries must stay derived and boundary-aware.
