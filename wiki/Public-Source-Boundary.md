# Public Source Boundary

Back to [[Home]].

The private Failure Atlas source exists and is source-locked outside this public-safe branch.

This branch includes only public-safe protocol surfaces, summaries, schemas, examples, and boundary notes.

## Rules

- Raw/internal taxonomy artifacts are intentionally excluded from public branch history.
- Public summaries must not imply the private source is included.
- Public summaries must not downgrade private/internal classifications.
- Public summaries must not claim the taxonomy is exhaustive.
- Public summaries must not claim `oz-skilltree` guarantees zero bugs.
