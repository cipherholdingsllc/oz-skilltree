# Bug-Cognizant Skill

Purpose: future-build-aware architecture prediction.

Given XYZ, predict:

- likely future builds
- integrations
- consumers
- language/runtime boundaries
- data/state contracts
- extension points
- future bug families
- refactor hazards
- scale traps
- observability hooks
- verification hooks
- what not to build yet
- recommended architecture

Bug-Cognizant does not create receipts itself. It defers receipt creation to `/oz-start`.
