# oz-skilltree Skill

Purpose: apply the full failure-aware execution loop to AI-assisted software work.

Core promise: Predict failure. Route safely. Prove the result. Leave a receipt.

## Components

- `/oz-start`
- Failure Radar
- Countermap-50
- Pathfinder
- YellowBrickRoad
- OzReceipt
- `/oz-result`
- Bug-Cognizant lens

## Guardrails

- No runtime activation.
- No hidden automation.
- No benchmark claims without evidence.
- No public/private classification downgrade.
- No collapse of claimed into verified.
- No collapse of committed into pushed.
