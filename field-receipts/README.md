# Field Receipts

Empty by design.

This directory holds sanitized receipts from real-world protocol use. Entries are added only when real receipts pass sanitization (`npm run check:private`) and operator review. Entries are published in batches, never as single anecdotes.

Rules:

- No fabricated, hypothetical, or placeholder entries — ever.
- No names, employers, private paths, or identifying details.
- Honest friction notes are required: a receipt that only reports wins is incomplete.
- Provenance is stated honestly; "reconstructed from operator recall" is an acceptable provenance, invented precision is not.

Use [INTAKE_TEMPLATE.md](INTAKE_TEMPLATE.md) to capture a session.
