# Bug-Cognizant

Bug-Cognizant is a future-build-aware architecture prediction lens.

Given XYZ, it predicts:

- likely future builds
- integrations
- consumers
- language/runtime boundaries
- data/state contracts
- extension points
- future bug families
- refactor hazards
- scale traps
- observability hooks
- verification hooks
- what not to build yet
- recommended architecture

## Receipt Boundary

Bug-Cognizant does not create receipts. If prediction turns into serious implementation, invoke `/oz-start`.

## Good Output

Good Bug-Cognizant output is compact and architectural. It names future pressure without building a runtime, dashboard, framework, or speculative automation layer.
