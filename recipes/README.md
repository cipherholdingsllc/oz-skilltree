# Recipes

Recipes are small operator playbooks that combine skills and schemas.

## Serious Repo Task

1. Run `/oz-start`.
2. Select Failure Radar mode.
3. Build Countermap.
4. Select YBR route.
5. Execute inside approval ceiling.
6. Run verification.
7. Close with `/oz-result`.

## Public Artifact Review

1. Classify public/private boundary.
2. Check claims against evidence.
3. Reject private implementation details.
4. Preserve truth states.
5. Leave a receipt with rejected claims and proof gaps.
