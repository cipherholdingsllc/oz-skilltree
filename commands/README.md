# Commands

Open these first:

1. [oz-start.md](oz-start.md) starts serious goals and creates/drafts OzReceipts.
2. [oz.md](oz.md) handles continuation-only upgrade, repair, comparison, compression, judgment, or pathfinding.
3. [oz-result.md](oz-result.md) closes or updates one active receipt.
4. [oz-handoff.md](oz-handoff.md) compresses one active receipt into a handoff brief any fresh session can resume.
5. [bug-cognizant.md](bug-cognizant.md) predicts future build surfaces without creating receipts.

Command docs describe the contract. They do not install or activate a CLI.
